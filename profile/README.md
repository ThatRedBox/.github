**"What's that red box?"**, you ask? That **Red[box]** is a Raspberry Pi™ made IoT-ready with the [Edgeberry](https://github.com/Edgeberry) ecosystem, loaded with the [Edge Explorer Hardware Cartridge](https://github.com/ThatRedBox) providing it with the JST-4 pin connector standard for compatibility with a wide range of hardware breakout ecosystems, purpose-built for [Node-RED](https://nodered.org). If those words sound familiar, you know we're talking about an engineering playground!
